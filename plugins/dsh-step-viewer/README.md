# dsh-step-viewer · 执行过程

独立DSH插件。安装后出现在 **插件 → dsh-step-viewer**，可单独开关和卸载；启用后，在聊天会话标题旁点击 **执行过程**。

这不是只有“正在思考”的提示：每条工具记录可展开实际工具名、调用参数JSON、command/code/content/patch等代码正文、真实工具返回JSON和文本；支持复制当前显示、错误筛选、工具名/步骤筛选、读取更早的会话记录。模型只提出调用但还没有执行记录时会明确标记，不冒充已执行。已有会话也可以查看，无需重跑任务。

## 真实数据的范围

- 从当前会话的官方 `uiSession` / `eventSource` 读取 `tool/call`、`tool/result`、公开的 `assistant/message` 与实时分片。
- 逐条显示DSH收到的内容，不生成或猜测内部思考，不用固定状态文案替代实际调用参数和返回。
- **网页端只有摘要被传入DSH时，仍明确标记为“网页进度摘要”。本插件不能凭空还原未传入DSH的网页原始工具参数/返回，也不读取本助手的私有思维链。**
- DSH工具记录不必然意味着在本机执行；执行位置由具体工具/连接器决定。“已返回”不是对文件落地或整个任务成功的承诺。
- 系统/开发者消息、模型请求头和会话内部配置不在显示白名单中。

## 启停和安装

插件包无运行时npm依赖、无安装脚本；复用DSH已有React、会话源和界面插槽。

在DSH插件管理的“添加插件”中可选择本地目录：

`<便携包根目录>\plugins\dsh-step-viewer`

也可用DSH官方CLI安装该绝对路径。不能把文件复制到安装包node_modules就宣称安装完成；必须通过正式profile/plugin管理路径注册，并核实启用状态。

关闭插件会卸载“执行过程”入口、面板和事件订阅。它不停止正在进行的模型/工具任务，也不清除已有会话。原网关的基础进度流与此显示插件是不同层，关闭本插件不改动原有网关策略。

## 隐私和边界

- 只读当前选中会话。不扫描其他会话，不调用模型，不注册/执行/重放工具，不改变网关绑定、保护锁、超时或沙箱权限。
- 无新增网络请求通道、遥测或落盘日志；“读取更早记录”只使用DSH已有当前会话的只读分页。
- 文本采用React文本节点，不渲染工具输出里的HTML/脚本或外部图片。
- 默认遮盖常见密钥字段和Bearer值，复制使用显示版本；不能保证识别代码中的所有敏感内容，复制前请检查。
- 最近500条可视记录；最多处理已加载窗口尾部20000个事件。单个显示区200000字符，超过时明确提示截断，原始会话不被修改。

## 验证

`node --test tests/model.test.mjs`：真实事件结构、参数/代码/结果、失败与未返回、跨步骤配对、重复/孤立结果、实时结算去重、摘要标记、私密事件排除、遮盖与容量限制。

React + jsdom界面测试覆盖打开、实时更新、展开、复制、脚本不执行、只读分页，以及关闭/卸载后订阅释放；这属于界面组件测试，不等于已在用户DSH窗口中验收。

`tests/installed-contract.mjs` 在Windows加载安装版DSH的bundle解析器与插件管理入口检查本包格式，不进行网络或模型请求。

开发：`python build.py` 生成自包含客户端模块 `client.js`。安装后的启停以DSH官方插件管理器为准。
