# 便携版分发边界

包含独立 Python、Node.js、Qt WebEngine 与 Python 依赖，不需要用户安装运行环境；不包含浏览器、DSH 主程序、账号登录状态或模型服务。

不包含作者的 .console、logs、.git、.venv、诊断备份、历史报告、个人工具清单或已安装 DSH 接收补丁。工具参考 manifest 为零工具模板，普通客户端工具仍以内联定义工作；参考文档试验不是开箱功能。

DSH 插件 0.1.1-gpl.1 为 GPL-3.0-only，附完整源码。Qt 相关库遵守各自 GPL/LGPL 条款，可替换兼容的修改版本，未设置签名锁定；请保留第三方许可和源码获取说明。

不修改系统 PATH、注册表、其他软件配置或现有运行实例。启动器不执行 pip、不更新依赖。普通入口不禁用 Qt 沙箱；另有明确警告并要求确认的兼容入口，仅在该进程树关闭 Qt 渲染沙箱。首次依赖已由制包过程安装到独立副本。

默认 API Key arena-local 是公开开发值，接收者应设置自己的 Key。测试夹具里的重复 UUID、保留域名邮箱和密钥样例不是实际账户。历史模型／实例标签仅为兼容代码，没有附带绑定。

源码修改限于便携解释器／Node 路径选择、嵌入式解释器测试入口及启动器；第三方运行库保留许可。打包机器验收不代表所有 Windows 版本、GPU、安全软件和路径环境都已覆盖；以验证报告列出的结果为准。

普通沙箱模式在打包机未通过原生窗口验收；可选兼容模式通过了隔离原生窗口与 JS/Python 桥测试。二者结果不得混为“安全默认模式已验收”。
