# 便携版构建与第三方许可

主项目保留 GPL v3 文本，独立 DSH 插件为 GPL-3.0-only。2026-10-19 的便携修改：解释器／Node 优先从 runtime/ 选择；启动器不安装依赖；运行目录可搬迁。所有项目源码随包提供。

## 可重建材料

`THIRD-PARTY-SOURCES.json` 列出官方运行时下载地址及 SHA-256、每个已安装 Python 包的版本、许可路径、可用源码发行包及摘要。`runtime-requirements.lock.txt` 固定本包依赖版本。

从官方 Python 嵌入式 x64 ZIP 创建 runtime/python，python313._pth 内容为 python313.zip、.、Lib/site-packages、../..、../../desktop、import site（各占一行）。在独立构建目录使用 pip --python 指向该解释器，再按锁文件安装；不要用作者的虚拟环境或配置。Node 官方 x64 ZIP 中 node.exe、LICENSE、README.md 放到 runtime/node。核验 Node 官方 SHASUMS256.txt。

删除安装生成的 Scripts/*.exe 和 __pycache__，避免构建机绝对路径进入分发。保留所有 dist-info 许可及原生 Qt 资源。编译器运行库仅从官方下载／wheel 已附带的 DLL 复制为 app-local DLL，不从系统安装目录采集私人文件。发布前运行离线测试及迁移路径验收，打包时排除运行生成的数据。

## 第三方源码与许可

- Python：runtime/python/LICENSE.txt；精确源码地址见 THIRD-PARTY-SOURCES.json。
- Node.js 及所含第三方库：runtime/node/LICENSE；官方源码和构建说明由该版本源码发行包提供。
- PySide6 / Shiboken / Qt 6.8.3：保留 Lib/site-packages 下各包的 dist-info/licenses、Qt 原有许可及第三方说明。PySide/Shiboken 与 Qt 完整官方源码下载地址列于 JSON。完整 Qt 源码包含 QtWebEngine 等模块及其第三方源码／许可证；构建配置和补丁以相应官方发行材料为准。
- 其他 Python 包：dist-info 中的许可证与源码链接见 JSON。不得因本项目 GPL 标签而移除各依赖原有许可。

动态库保持可替换，未施加反调试／反修改条款。校验清单仅用于完整性检查。再分发本包时须同时保留这些许可和对应版本源码获取说明，并确保源码持续可获得；若外部源码地址失效，分发者应提供对应源码，而不是声称闭源免除义务。

嵌入式解释器会忽略部分 PYTHON* 环境变量。本版启动器和子网关明确使用 `-X utf8 -B`，保证中文路径和文本解码，并避免运行时生成构建路径字节码。测试入口也为子解释器显式启用 UTF-8。
